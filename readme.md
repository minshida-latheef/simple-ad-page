\# Simple Ad Landing Page



A beginner-friendly product advertisement landing page built with vanilla HTML, CSS, and JavaScript.



\## Features

\- Top promotional offer banner

\- Responsive product feature cards

\- Interactive discount code reveal button



\## Tech Stack

\- HTML5

\- CSS

\- JavaScript



\## How to Run

1\. Download or clone the repository.

2\. Open `index.html` in any web browser.
